# Clinical Framework — DEMO

> ⚠️ **Demo only.** All clinical content in this repository is made up for demonstration purposes. It is not clinical guidance.

This is where we keep the **clinical framework** (our source of truth) and track every **open clinical question** until it is decided.

## How to use it (no technical knowledge needed)

**I have a clinical question that needs an answer**
Go to the **Issues** tab → **New issue** → choose **Open clinical question** → fill in the form.

**I've been asked to answer a question**
Open the question in the **Issues** tab and reply in the comment box at the bottom, just like commenting in a Word document.

**I want to see what's open and what's been decided**
Go to the **Projects** tab → open the **Decision Register** table.

**I want to suggest a change to the framework**
Open the page in the `framework` folder → click the ✏️ pencil icon → make your change → click **Commit changes…** → choose **Propose changes**. Tom will review and approve it.
