# Demo script (delete this file before sharing with clinicians)

## Sample questions to create through the form
1. **Vitamin D** — Two reference ranges are in circulation. Which one goes in the framework? Destination: Clinical framework.
2. **Ferritin** — Do we need to know menstrual cycle phase to interpret ferritin? Destination: Both (framework + product needs to collect cycle data).
3. **Female hormone panel** — Should we report results for members on hormonal contraception? Destination: Clinical framework.
4. **Ferritin** — Can the lab machine run ferritin from the same sample as the hormone panel? Destination: Neither (just unblocks work).

## 10-minute walkthrough
1. (1 min) The problem: 100+ Word docs, five versions of one reference range, no decision log.
2. (2 min) Raise a question: New issue → fill the form.
3. (2 min) Answer it: comment as the expert, record the decision, set Status to Decided.
4. (3 min) Update the framework: edit vitamin-d.md → Propose changes → "Closes #1" → Tom approves → merge.
5. (2 min) The payoff: open the Decision Register table; open vitamin-d.md → History → click the change → see it links to question #1, who decided, and when.
