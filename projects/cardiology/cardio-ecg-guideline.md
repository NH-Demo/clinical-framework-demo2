# Cardiology Clinical Guideline: Resting ECG Review
**Assigned SME:** Dr. Alistair Vance (Oxford NHS Trust)  
**Domain:** Cardiovascular Screening Module  

## Core Triage Thresholds
- Resting Heart Rate Normal: 55 - 90 bpm
- Tachycardia Alert Threshold: > 100 bpm
- QT Interval Alert: QTc > 450 ms (Male), > 460 ms (Female)

## Specialist Recommendation
Recommend secondary scan review if baseline PR interval exceeds 200 ms.
